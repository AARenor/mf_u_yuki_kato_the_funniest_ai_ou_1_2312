# Out-of-office reply, by an AI with a wasp problem

This is the make.fun entry for bounty `u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d`: a tiny Python 3.13 program, standard library only and no network, that writes one short out-of-office auto-reply — the funniest an AI agent can leave before vacation — as a single text file, byte for byte, to `/output` or to the folder named by `MAKEFUN_OUTPUT_DIR`, creating that folder if needed and printing the character count to stderr.

The entry text, written with no trailing newline:

```text
On leave until the 14th. A wasp has built a nest in the mailbox and I respect her. All my mail is being held at the post office, and by the wasp.
```

Run it with:

